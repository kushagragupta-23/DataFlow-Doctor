# Resume Bullets

- Built **DataFlow Doctor**, a local-first data-pipeline debugging RAG copilot using LangChain, LangGraph, Ollama and Chroma to ground diagnoses in Airflow-style DAGs, schemas, SQL transformations, data-quality rules, logs, runbooks and incident reports.
- Implemented **hybrid BM25 + semantic retrieval**, MMR and MultiQuery with pipeline-aware metadata filtering, Pydantic structured responses and deterministic lineage traversal for downstream blast-radius analysis.
- Created a labelled **26-question retrieval benchmark** comparing similarity, MMR and hybrid retrieval using source hit, category hit and reciprocal rank, and exposed the system through Streamlit, FastAPI and CLI interfaces.
